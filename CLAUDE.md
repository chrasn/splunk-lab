# Splunk-lab

- Splunk-apper ligger i apps/<app>/default. Endre aldri filer i local/.
- Start alltid fra oppdatert test og lag en branch feature/<kort-navn>.
- PR-er går alltid mot test. Release-PR fra test til master lages bare når jeg ber om det.
- Merge aldri PR-er selv. Det gjør et menneske.
- Test nye SPL-søk mot Splunk (via MCP) før du lager PR, og vis resultatet i PR-beskrivelsen.
- Skriv commit-meldinger og PR-tekst på norsk.
